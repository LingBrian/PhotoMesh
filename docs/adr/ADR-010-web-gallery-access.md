# ADR-010：Web/Tauri 图库访问与媒体操作授权

- **状态：已批准（用户于 2026-10-22 明确批准）**
- **日期：** 2026-10-22
- **对应阶段：** M4
- **相关决策：** ADR-001（节点身份与图库授权）、ADR-002（墓碑不删除原图）

## 背景

> 以下为本 ADR 批准时（2026-10-22）的基线记录，不代表当前运行时状态。后续实现的 HTTP 路由、当前状态码及响应头以 `contracts/openapi_draft.yaml` 为准；P2P 消息不属于该 HTTP 契约。

当时 Node API 已有 `/v1/assets` 草案和受图库 ACL 保护的索引查询路由，但运行时尚未给它配置 HTTP 主体解析；`assets` 返回值也没有时间线所需的文件名、拍摄时间和来源位置。没有授权的浏览器/Tauri 客户端无法安全查询时间线，且没有下载原图或缩略图缓存接口。M4 需要这些能力，但不得让 UI 直接访问 SQLite、绕过图库 ACL，或让删除按钮触及任一节点的原图。

## 决策提案

1. **主体和权限：** Web/Tauri 通过用户配置的节点 URL 与当前节点管理员 Bearer 凭据访问 API。每个请求由 Node API 校验凭据；图库读取使用现有图库 ACL，管理员本地操作按管理主体授权。浏览器只将凭据保存在当前会话的内存中，刷新后重新输入；不写入 localStorage、IndexedDB、URL、日志或遥测。未经授权的图库和媒体请求返回 403/404，不暴露其是否存在。
2. **只读时间线：** 完善现有 `GET /v1/libraries` 与 `GET /v1/assets` 合约。资产列表使用不透明游标、每页最多 200 项、按 SQLite `capture_ts` 和稳定 `asset_id` 排序；返回原始文件名、拍摄时间、来源节点/路径摘要、可用性和资源版本摘要。查询必须留在 SQLite 服务端分页；UI 不下载全库。
3. **媒体读取：** 新增受同一主体和图库 ACL 检查的原图只读接口。原图接口只流式读托管存储或经授权的在线文件位置，不改写源文件；不可达时返回明确离线错误。当前版本由客户端在内存中缩放派生缩略图并写入浏览器 IndexedDB，缓存键包含节点、资产、资源版本；不得将缓存路径映射回原图写入位置。服务端缩略图生成可在后续性能测量后追加。
4. **本地清理与全局回收站：** 本 ADR 仅定义 UI 的明确范围，不实现物理永久删除。M4 中“仅本地清理”只清理当前客户端的可再生缓存；全局回收站只展示/恢复现有 tombstone 能力。永久删除原图、回收站彻底清空不提供按钮，也不增加 API。清理确认框显示影响范围和目标节点。
5. **节点与配对：** 节点列表展示用户添加/配对的端点、最近健康检查、在线/离线和信任状态。二维码邀请、发现和撤销继续使用现有配对 API；邀请秘密仅短暂显示，不持久化。未知 mDNS 节点先显示待验证地址，连接必须校验节点公钥/Peer ID。
6. **向后兼容：** 增量 OpenAPI/JSON Schema 变更，不修改 SQLite 迁移。旧客户端继续使用现有上传与健康检查路径。新字段可选；无分页/媒体能力的节点显示可理解的“不兼容版本”提示，不回退到全量扫描。

## 安全影响

- 新增读取路由会扩大敏感元数据和原图访问面，必须为每个路由加入有权限/无权限测试，且每次读取都重新执行 ACL。
- 管理员凭据只用于节点管理会话，UI 不把其伪装成设备配对身份；共享设备需主动退出并丢弃会话内存。
- 永久删除接口明确不属于本提案，避免把“清除本地缓存”与墓碑/源节点原图删除混为一谈。

## 测试和验收

- OpenAPI/JSON Schema 兼容检查及 API ACL 正反用例；游标分页稳定性、排序并列、撤销授权后的后续请求拒绝。
- 原图端点字节摘要与托管原图一致；离线来源有明确结果；读取不改变 SQLite 来源状态或原文件 SHA-256。
- Playwright 以 100,000 条确定性元数据记录验证查询分页、虚拟列表、搜索和滚动；保留浏览器/CPU/数据种子/P50/P95。
- UI 验收含中英实时切换、深浅主题、键盘焦点/ARIA、缓存清理仅影响客户端缓存、永久删除操作不可触发。

## 实施计划（批准后）

1. 先更新 OpenAPI/JSON Schema 和 API 安全测试，再实现 SQLite 游标查询、来源投影、缩略图/原图只读服务。
2. 实现 Vue Web/Tauri 共用图库页面和按节点 API client；默认不提供永久删除路径。
3. 增加 Playwright 端到端与 100k 固定种子性能场景，运行相关 pnpm lint/typecheck/test/contracts/build 和 E2E。
