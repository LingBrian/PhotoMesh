# ADR-024：PM-051 Web 批量选择与可逆元数据操作

- **状态：** PM-051 已在隔离 `feat/pm051-bulk-operations` worktree 实现并验证；仅涉及 Web UI 与测试，不改变服务端 API、OpenAPI 或数据库。
- **日期：** 2026-10-29
- **路线图：** PM-051（批量选择与可逆标签/收藏操作）。
- **依赖：** PM-041/043 标签 API 与 Web 标签视图；PM-046 收藏状态/API/能力标志；PM-050 时间线搜索状态。

## 背景与目标

当前 Node 已提供逐资产、经图库授权的标签 PUT/DELETE 与共享收藏 PUT API；没有批量 API，Web 也没有批量选择界面。PM-051 要求用户清楚知道选择数量和影响范围，部分失败可重试，且不出现批量破坏性操作。本切片只调用已有逐资产 API，不扩大服务端或同步协议。

## 决策

1. Web 提供显式资产复选框；一批最多 100 项，作用域为当前已连接图库中被明确勾选的资产（不是当前搜索匹配、所有结果、其他图库或未加载项目）。在确认前清楚显示所选数量、图库标题、目标标签/共享收藏状态。切换图库、会话失效或搜索词改变时清空选择。
2. 可用操作仅为对所选资产添加/移除一个指定标签，以及设置图库级共享收藏为“收藏/取消收藏”。收藏是所有获授权节点共享的状态，不是个人书签；旧 Node 未声明 `assetFavorites` 或 `assetTags` 时对应操作禁用。没有“切换每个资产当前状态”的模糊动作。
3. 不新增 Node batch endpoint。客户端对选中资产按稳定顺序串行调用现有单项 API，降低并发压力；只接受来自当前图库与选择快照中的资产。标签仅通过既有 tag endpoint 操作；共享收藏每个资产先分配唯一 UUID `Idempotency-Key`，首次失败后的重试复用同一 key，处理“服务端已提交但响应丢失”的情况。
4. 每项分别显示成功/失败；一个请求失败不回滚成功的其他项；只重试失败项，且保留原目标和幂等键。对话框展示总项数、完成/失败数及范围；成功项更新当前 Web 状态。会话/图库范围重置时，在途项按结果未知、未启动项与已确认结果以不含资产标识的会话内摘要显示，不自动迁移或重试到新会话。批量删除资产、原图、永久删除、清空缓存或其他不可逆动作不属于此 UI。
5. 选择、操作和重试状态仅驻留当前会话内存；不写 localStorage/URL。权限仍由每个 Node API 请求验证；Node 端拒绝时保留可重试失败状态，不把失败显示成成功。

## 交付计划与验收

- **输入：** 当前授权图库的已加载资产、health capability、用户逐项选择、一个标签值或明确收藏目标。
- **输出：** 带逐项状态的单一批次；成功的 tags/favorites 更新内存 gallery view，失败项可再次安全提交。
- **风险控制：** 上限 100、串行请求、图库绑定、确认弹窗、每项授权、收藏稳定幂等键、无破坏性动作。服务器不可用或授权撤销时不隐藏部分成功。
- **验证：** 已先添加失败的 helper/E2E 测试再实现；Web 单测验证 100 项上限，Playwright 覆盖逐项标签/收藏写入、明确数量与图库范围、capability 门控、失败项重试及收藏幂等键复用、搜索/图库变更清空选择、会话重置时区分已确认/未知/未开始项且不自动重试，以及无破坏性端点；根级 `pnpm install --frozen-lockfile`、lint、typecheck、test、contracts:check、build 均通过，完整串行 Playwright 27/27（含 100k 分页回归）通过；截图见 [`pm051-bulk-operations.png`](../screenshots/pm051-bulk-operations.png)。
- **边界：** 无 migration、API/contract、原图读写或新增依赖；只允许隔离分支本地 Conventional Commit；不 push、merge、release、部署或执行生产迁移。
