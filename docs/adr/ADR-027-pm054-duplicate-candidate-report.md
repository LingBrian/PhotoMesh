# ADR-027：PM-054 重复内容候选报告

- **状态：** 用户已批准继续推进 PM-053–PM-100；本 ADR 将重复候选限定为隔离 worktree 内的只读本地实现。不得自动合并、删除、写墓碑或改写媒体。
- **日期：** 2026-10-30
- **路线图：** PM-054（重复内容候选查询）。
- **依赖：** PM-048/049 Gallery 授权查询、PM-053 日期来源字段、现有 `assets`/`asset_files`/同步投影。

## 决策

1. 以规范 SHA-256 和 byte size 作为候选分组键；只有同一图库内至少两个可见资产共享 SHA-256 才报告。相同内容但不同来源、路径、节点或资产 ID 仍作为独立资产返回。
2. 仅提供授权后的只读报告接口 `GET /v1/assets/duplicate-candidates?libraryId=...&limit=...`，返回有限数量的候选组及每个资产的来源、路径、节点、可用性、大小和哈希。接口不接受写操作、确认参数或删除参数。
3. 结果按 `sha256` 二进制序稳定排序，组内按 `assetId` 二进制降序；单次最多 100 组、每组最多 32 个资产，防止异常数据造成无界响应。超出组成员以 `truncated` 标记，不隐藏候选组。
4. 查询排除 tombstone 资产，并保留远程同步投影；不存在本地原文件的远程资产仍可作为候选报告，但不暗示本机有备份。
5. 不新增数据库字段、迁移或 P2P 事件；复用现有内容哈希和授权边界。路径字段仅在已有图库读取授权后返回；更细粒度隐私最小化策略由 PM-058 另行决定。
6. OpenAPI DTO 字段为可选扩展，不改变现有 Gallery `/v1/assets` 分页语义。未来审阅 UI（PM-055）不得在本 ADR 范围内实现自动动作。

## 风险与验收

- 同哈希不一定代表用户希望合并；报告文案必须明确“候选”而非“重复事实”。
- 哈希冲突理论上可能误报，因此返回完整哈希供人工复核。
- 测试覆盖授权拒绝、tombstone 排除、local/remote 混合、不同路径保留、组/成员上限及稳定排序；根级验证通过后仅本地提交。

## 实施边界

本 ADR 仅授权本地源码、合同、测试和隔离分支提交；不授权生产迁移、push、merge、release、部署、自动合并、删除原图或写入墓碑。
