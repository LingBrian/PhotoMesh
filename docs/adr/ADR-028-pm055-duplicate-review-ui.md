# ADR-028：PM-055 重复候选审阅界面

- **状态：** 本地实现完成，限隔离 worktree；不授权生产部署、push、merge 或发布。
- **日期：** 2026-10-30
- **路线图：** PM-055。

## 决策

1. Web 仅在 Node health 宣告 `duplicateCandidates` 时显示“重复候选”入口，并通过已授权 API 读取候选组。
2. 每组展示 SHA-256、大小、文件名、来源路径、来源节点和可用性；明确说明相同哈希只是人工复核证据。
3. “忽略”只保存在当前浏览器会话内，不写数据库、不生成 P2P 事件、不删除/合并/移动原图；刷新或重新连接后候选重新出现。
4. 离线、未授权、空结果和受限成员均有明确状态；接口的 100 组/32 成员上限在 UI 中标注为可能截断。

## 验收

Web lint、typecheck、unit tests 通过；Node/OpenAPI PM-054 合同继续验证。后续 PM-056/058 负责更细的状态分类和路径最小化策略。
