## 立即开始的建议

1. 将 `codex/AGENTS.md` 的规则用于仓库根目录的 `AGENTS.md`；当前生效文件已位于根目录。
2. 在 GitHub 创建 **Apache-2.0** 开源仓库，配置分支保护与必过 CI。
3. 使用 `codex/阶段提示词.md` 的 **M0** 提示词初始化 Monorepo，再按 M1→M2→M3 的依赖顺序实施。
4. **不先开发 AI**：首发 Windows、Android、NAS 核心，先完成原图不可变备份与两主节点 P2P；Linux 主节点与 Web 客户端可随主节点服务及 Vue 代码扩展。
5. 每次阶段验收保留运行日志、测试报告和原图 SHA-256 证据。

## 关键边界

- 完全去中心化意味着不强制中心服务器；不意味着所有 NAT 场景都能无公网资源直连。
- 各主节点独立保管原图；P2P 默认同步**有权限的元数据及事件**，原图按需传输，不默认复制整个文件库。
- 端到端加密与服务端 AI 有天然张力：只有被用户授权的可信执行节点才能解密内容；未授权的云服务无法直接分析密文。
- 回滚与数据恢复属于不同动作。数据库迁移不可逆时必须使用经验证的升级前快照或前向修复迁移。
- “10 万照片 P95 < 1 秒”等属于**验收目标**，须在规定的硬件、数据集和查询条件下实测。
